Diagnostic

Diagnostic exports for troubleshooting. Network Capture uses browser-level capture on desktop and page-level fetch/XHR capture on Android. Mobile capture is bounded to 100,000 events and may pause if Android suspends the game tab; keep the tab open overnight for best coverage.

Downloads

Save the exact diagnostic state currently captured by Manager.

What to capture for a problem
  • Numbers don't match the game (profit, cost): open the building in the game and scroll to its Profit Calculator, then open Production here and tap that building, then Download Diagnostic Bundle. Also send a screenshot of the game screen.
  • Something isn't updating: Start Network Capture, do the action in the game (collect, buy, sell), come back, Download Network Capture, then the Bundle.
  • Slow / laggy: download the Bundle right after it happens (it now includes storage sizes and the last 200 background jobs).
